    Guide pratiche

    Uno degli scopi del progetto è quello di facilitare il percorso di rilascio di materiale, nuovo o già esistente, in una forma che sia compatibile con i nostri obiettivi.

    Questa sezione raccoglie link a materiale utile per creare un nuovo repositorio o per migrare materiale già esistente nella forma di un repositorio su codeberg.

    Cosa è un repositorio?

    In costruzione

    Dobbiamo capire un attimo le persone a cui ci rivolgiamo, ma immagino che qui abbiamo bisogno di un minimo di documentazione su come si interagisce con un repositorio git.

    Strumenti e template

    Questa sezione contiene una breve lista di strumenti liberi che possono essere utili per la preparazione di materiale didattico. La lista, va da sé, non è esaustiva, e può evolvere nel tempo.

    LibreOffice

    LibreOffice è un word processor libero di tipo WYSIWYG. In questo caso la struttura del repositorio, almeno nei casi più semplici, è banale: il file .odt, il file .pdf e la licenza.

    Link al template LibreOffice

    LaTeX

    LaTeX è un linguaggio di markup per la preparazione di documenti, fortemente orientato alla matematica ed alle materie tecniche (ma non per questo inadatto a documenti non tecnici, specialmente se complessi.) Il formato tipico del prodotto finale è il pdf.

    Link al template LaTeX.

    Quarto

    quarto è un sistema di impaginazione e grafica, molto adatto per le applicazioni scientifiche e tecniche, basato su un linguaggio di markup, e che supporta diversi tipi di output, tra cui html e pdf.

    Link al template quarto.

    MkDocs e Material

    MkDocs è di nuovo un sistema di composizione basato su un linguaggio di markup orientato alla creazione di siti html statici. Questa pagina web è stata realizzata con questa tecnologia.

    Link al template MkDocs + Material.
